FL1NK Ship Layout Editor

Map the ship boundary, five walking paths, staircases, and Captain's exit.

1. Select what to map

Boundary: Click around the inside edge of the ship walls.
Walking path: Click its start and end points only.
Staircase: Click the endpoint on each connected deck.
Exit: Click the center of the Captain's exit door.

2. Connect a staircase

For each staircase, click the lower-deck endpoint first and the higher-deck endpoint second. Then assign adjacent decks, such as Deck 1 → Deck 2.

3. Save or load your layout

Ready. Start by mapping the ship boundary.

Recommended order
  1. Trace and save the ship boundary.
  2. Select Walking Path and click two points for each deck.
  3. Adjust the width to match the deck's actual walking area.
  4. Map each staircase and assign its connected decks.
  5. Select Deck 5, choose Captain's Exit, and click the exit door.
  6. Export your JSON file and keep a backup.
